Duplicate Appointments
Same student & location within minutes → count only the earliest.
When the same Student ID has more than one appointment at the same Location within this window, only the earliest is counted — later appointments (and all of their services) are excluded. Matching uses Student ID + Location + Reported Start Date/Time; services are not part of the match. Rows with a missing Student ID or Start Date/Time are never excluded.
